# Ponte São Luís – Baixada

Site: https://pontesaoluisbaixada.com.br

**Iniciativa popular**, sem vínculo com o Governo do Maranhão, o Governo Federal nem com as prefeituras. O objetivo é chamar a atenção dos governos, das prefeituras e de investidores privados para a importância e o impacto positivo de uma ponte rodoferroviária entre São Luís e Alcântara.

- Maquete 3D: `index.html` (Three.js)
- Estudo e vídeo: `estudo.html`
- Apoio e comentários: `apoie.html` (os dados ficam no Supabase)

Ideia: PAULO SERRA. Maquete, estudo, vídeo e site feitos com inteligência artificial, pelo Claude (Anthropic).
